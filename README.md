# Abhishek Abraham T A - Portfolio

A fabulous personal portfolio webpage with flashy animations, sparkle particles, and a responsive design.

## Live Preview

Visit: [https://abhishekabrahamta.github.io](https://abhishekabrahamta.github.io)

## Features

- Round profile photo in a glowing pink circular frame
- Shimmer text animation on the name
- Floating sparkle particles and mouse trail effect
- Hobby section with hover effects
- Fully responsive design (mobile-friendly)
- Black background with gradient mesh overlay

## Tech Stack

- HTML5
- CSS3 (animations, gradients, flexbox)
- JavaScript (particle generator, mouse trail)
- Google Fonts (Poppins)
